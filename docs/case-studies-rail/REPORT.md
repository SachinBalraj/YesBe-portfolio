## Implementation
- New section id: `selected-work`; accessible via `aria-labelledby="case-studies-heading"`.
- Heading is first in DOM for screen readers and visually ordered below the cards via flex `order`, preserving the intended layout.
- Desktop (`min-width: 1200px`, no reduced motion):
  - Six cards in one horizontal row, four visible initially.
  - Sticky viewport beneath the 76px fixed header.
  - Scroll-driven `translate3d` computed from real `track.scrollWidth - viewport.clientWidth`.
  - Pin distance clamped to 520–1100px using a 1.25 multiplier.
  - End state shows cards 3–6; scrolling back reverses smoothly.
  - Sticky is released correctly when the section ends.
- Tablet:
  - Static section, native horizontal swipe, approximately two cards visible.
- Mobile:
  - Static section, native horizontal swipe/snapping, one card plus next-card preview.
- Reduced motion:
  - No pinning or transform; accessible three-column grid, one column on small screens.
- Overlap:
  - Cards overlap the hero/white boundary by 25% of card height and sit 75% in the white section at desktop, tablet, and mobile widths.
- The global stylesheet was not changed. A homepage-only `html:has(.case-rail), body:has(.case-rail) { overflow-x: clip; }` override is scoped to this section because the existing global `overflow-x: hidden` prevented sticky positioning.
